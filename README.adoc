= Publications bibliographic data for Relaton-IANA

This repository is used by Relaton-IANA to represent known publications.

Data is stored in Relaton YAML format.

This repository uses the IANA flavor of the
https://github.com/relaton/relaton[relaton] gem to fetch the documents, and runs
daily. `relaton-iana` no longer exists as a gem of its own -- the flavor lives in
the combined `relaton` gem.

== Indexes

Two indexes are published, both zipped and committed by `relaton/support`'s
shared `crawler.yml`:

`index-v2`:: The current, pubid-keyed index. Written by
`Relaton::Iana::DataFetcher` itself, with each row's `:id` a
`Pubid::Iana::Identifier` serialised to its `_type: pubid:iana:registry` hash.

`index-v1`:: The legacy string-keyed index, kept alive for every released
`relaton` line that still reads `index-v1.zip` from this branch. The gem no
longer writes it, so `crawler.rb` rebuilds it here through `index_builder.rb`,
reading each `data/*.yaml` document's `docnumber`.

`index_builder.rb` cross-checks its rows against the index the fetch just wrote
and fails the crawl if any id has no data file of its own. That means two
docnumbers collided on one filename in the gem's `output_file`, and the index
would otherwise be published short.

== Browsable index

The dataset is published as a searchable index site at
https://relaton.github.io/relaton-data-iana/.

It is built by `.github/workflows/deploy.yml`, which calls the shared
https://github.com/relaton/support/blob/main/.github/workflows/data-deploy.yml[`relaton/support` deploy workflow]
to run `relaton index` over `data/` and deploy the result to GitHub Pages.

The page's title, favicon and description are *not* configured here -- they live
in the `repo: iana` entry of
https://github.com/relaton/support/blob/main/data-index/configs.yml[`relaton/support`'s `data-index/configs.yml`].
Cimas syncs `deploy.yml` into this repo as a whole-file copy, so branding kept
here would be silently reverted on the next sync.
